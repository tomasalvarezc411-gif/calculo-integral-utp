1. MISIÓN TEÓRICA

La Regla de Simpson (1/3) aproxima la curva mediante arcos de parábola que conectan tríos de puntos consecutivos. Requiere obligatoriamente que el número de subintervalos n sea par:

Sₙ = (Δx / 3) · [ f(x₀) + 4 f(x₁) + 2 f(x₂) + 4 f(x₃) + ... + 4 f(xₙ₋₁) + f(xₙ) ], donde Δx = (b - a) / n

Cota del Error Teórico:

|Eₛ| ≤ K · (b - a)⁵ / (180 n⁴), donde K = máx |f⁴⁾(x)| en [a, b]

3. EJERCICIOS

1. Aproxime ∫₀² x² dx usando la regla de Simpson con n = 4.

💡 Pista para iniciar: Identifica a = 0, b = 2 y n = 4 (n es par). Calcula Δx = (2 - 0) / 4 = 0.5. Evalúa f(x) = x² en x₀ = 0.0, x₁ = 0.5, x₂ = 1.0, x₃ = 1.5 y x₄ = 2.0, aplicando los patrones de coeficientes 1, 4, 2, 4, 1 divididos entre 3.

2. Use S₄ para aproximar ∫₁³ (1 / x) dx.

💡 Pista para iniciar: Con a = 1, b = 3 y n = 4, se tiene Δx = (3 - 1) / 4 = 0.5. Los puntos son xᵢ ∈ {1.0, 1.5, 2.0, 2.5, 3.0}. Evalúa f(x) = 1 / x y multiplica por el vector de pesos (1, 4, 2, 4, 1) · (Δx / 3).

3. Calcule S₆ para ∫₀¹ eˣ dx.

💡 Pista para iniciar: Divida el intervalo en n = 6 subintervalos (Δx = 1 / 6 ≈ 0.1667). Evalúa f(x) = eˣ en xᵢ = i / 6 para i = 0, 1, 2, 3, 4, 5, 6 con la ponderación 1, 4, 2, 4, 2, 4, 1.

4. Aproxime ∫₀^π sin(x) dx usando S₄.

💡 Pista para iniciar: Para [0, π] con n = 4, el paso es Δx = π / 4. Los puntos a evaluar en f(x) = sin(x) son 0, π/4, π/2, 3π/4 y π.

5. Use S₄ para aproximar ∫₀¹ √(1 + x³) dx.

💡 Pista para iniciar: Con a = 0, b = 1 y n = 4, la distancia es Δx = 0.25. Evalúa f(x) = √(1 + x³) en 0.00, 0.25, 0.50, 0.75 y 1.00.
