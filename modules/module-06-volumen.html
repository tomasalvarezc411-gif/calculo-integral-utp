1. MISIÓN TEÓRICA

La Integración Directa aplica directamente la tabla de fórmulas antiderivadas fundamentales simplificando previamente la expresión mediante álgebra básica (desarrollo de potencias, distribución de denominadores y propiedades de exponentes):

Regla de la Potencia: ∫ xⁿ dx = (xⁿ⁺¹ / (n + 1)) + C, con n ≠ -1
Regla Logarítmica: ∫ (1 / x) dx = ln|x| + C

3. EJERCICIOS

1. Calcule ∫ (ax + by)² dx.

💡 Pista para iniciar: Expande el binomio al cuadrado: (ax + by)² = a²x² + 2abxy + b²y². Como la integración es con respecto a x, las variables a, b e y actúan como constantes. Aplica la regla de la potencia término a término: ∫ a²x² dx + ∫ 2abxy dx + ∫ b²y² dx = (a² x³ / 3) + ab y x² + b² y² x + C.

2. Calcule ∫ (3 / x² - 9√x) dx.

💡 Pista para iniciar: Reescribe cada término en forma de potencia: 3x⁻² - 9x^(1/2). Aplica la regla de la potencia ∫ xⁿ dx = xⁿ⁺¹ / (n + 1) para cada término: 3(x⁻¹ / -1) - 9(x^(3/2) / (3/2)) + C = -3/x - 6 x^(3/2) + C = -3/x - 6 √(x³) + C.

3. Calcule ∫ ((x + 4) / √x - 4 / x) dx.

💡 Pista para iniciar: Distribuye √x = x^(1/2) en el numerador: (x / √x) + (4 / √x) = x^(1/2) + 4x⁻(1/2). Reescribe la integral como ∫ (x^(1/2) + 4x⁻(1/2) - 4/x) dx. Integra término a término: (2/3)x^(3/2) + 8√x - 4 ln|x| + C.

4. Calcule ∫ (x - 1 - 1 / x) dx.

💡 Pista para iniciar: Integra cada término de forma inmediata: ∫ x dx - ∫ 1 dx - ∫ (1/x) dx. Obteniendo: (x² / 2) - x - ln|x| + C.

5. Calcule ∫ (x - 1)(x + 1) dx.

💡 Pista para iniciar: Desarrolla el producto notable de diferencia de cuadrados: (x - 1)(x + 1) = x² - 1. Luego integra término a término: ∫ (x² - 1) dx = (x³ / 3) - x + C.
