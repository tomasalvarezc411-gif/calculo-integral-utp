1. MISIÓN TEÓRICA

El Teorema Fundamental del Cálculo conecta la derivación con la integración definida, permitiendo evaluar el área exacta bajo una curva continua f(x) mediante su antiderivada F(x):

∫ₐᵇ f(x) dx = F(b) - F(a), donde F'(x) = f(x)

Área entre dos curvas f(x) y g(x):

Área = ∫ₐᵇ |f(x) - g(x)| dx = ∫ₐᵇ [Arriba(x) - Abajo(x)] dx

3. EJERCICIOS

1. Calcule ∫₀² (3x² - 2x + 1) dx.

💡 Pista para iniciar: Integra término a término: ∫ (3x² - 2x + 1) dx = x³ - x² + x. Luego evalúa los límites de integración aplicando el Teorema Fundamental del Cálculo: F(2) - F(0) = (2³ - 2² + 2) - (0³ - 0² + 0) = (8 - 4 + 2) - 0 = 6.

2. Evalúe ∫₁ᵉ (1 / x) dx.

💡 Pista para iniciar: La antiderivada de 1 / x es ln|x|. Evalúa en los límites de 1 a e: F(e) - F(1) = ln(e) - ln(1) = 1 - 0 = 1.

3. Calcule ∫₀^(π/2) cos(x) dx.

💡 Pista para iniciar: La antiderivada de cos(x) es sin(x). Evalúa de 0 a π/2: F(π/2) - F(0) = sin(π/2) - sin(0) = 1 - 0 = 1.

4. Determine el área de la región limitada por f(x) = x² y g(x) = 2x.

💡 Pista para iniciar: Encuentra los puntos de intersección igualando x² = 2x, de donde x² - 2x = 0, obteniendo x = 0 y x = 2. Como g(x) = 2x ≥ f(x) = x² en el intervalo [1], calcula el área integrando la diferencia: ∫₀² (2x - x²) dx = [x² - x³/3]₀² = (4 - 8/3) - 0 = 4/3 ≈ 1.3333.

5. Calcule el área bajo la curva f(x) = eˣ entre x = 0 y x = 1.

💡 Pista para iniciar: La antiderivada de eˣ es eˣ. Evalúa en el intervalo [2]: F(1) - F(0) = e¹ - e⁰ = e - 1 ≈ 2.7183 - 1 = 1.7183.
