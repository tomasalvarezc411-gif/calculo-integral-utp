1. MISIÓN TEÓRICA

La Regla del Trapecio conecta los puntos contiguos sobre la curva mediante segmentos rectos, aproximando la integral definida mediante trapecios:

Tₙ = (Δx / 2) · [ f(x₀) + 2 f(x₁) + 2 f(x₂) + ... + 2 f(xₙ₋₁) + f(xₙ) ], donde Δx = (b - a) / n

3. EJERCICIOS

1. Aproxime ∫₀² x² dx usando la regla del trapecio con n = 4.

💡 Pista para iniciar: Identifica a = 0 y b = 2. Calcula el ancho de subintervalo con Δx = (2 - 0) / 4 = 0.5. Luego, construye los 5 puntos de la malla x₀, x₁, x₂, x₃, x₄ sumando 0.5 sucesivamente a partir de x₀ = 0, y evalúa f(x) = x² en cada uno.

2. Use T₅ para aproximar ∫₁³ (1 / x) dx.

💡 Pista para iniciar: Con los límites a = 1 y b = 3, y n = 5, el ancho de cada subintervalo es Δx = (3 - 1) / 5 = 0.4. Determina los puntos de evaluación xᵢ ∈ {1.0, 1.4, 1.8, 2.2, 2.6, 3.0}, evalúa f(x) = 1 / x en cada uno y aplica los coeficientes 1, 2, 2, 2, 2, 1 en la fórmula.

3. Calcule T₆ para ∫₀¹ eˣ dx.

💡 Pista para iniciar: Divida el intervalo en n = 6 subintervalos iguales para obtener un paso Δx = 1 / 6 ≈ 0.1667. Evalúa la función exponencial f(x) = eˣ en los puntos xᵢ = i / 6 para i = 0, 1, 2, 3, 4, 5, 6.

4. Aproxime ∫₀^(π/2) sin(x) dx usando T₄.

💡 Pista para iniciar: Para el intervalo [0, π/2] dividido en n = 4 partes, la longitud de cada paso es Δx = (π / 2) / 4 = π / 8 ≈ 0.3927. Los puntos a evaluar en la función seno son 0, π/8, π/4, 3π/8 y π/2.

5. Use T₄ para aproximar ∫₁² √x dx.

💡 Pista para iniciar: Con a = 1, b = 2 y n = 4, el incremento constante es Δx = 0.25. Evalúa la función raíz cuadrada f(x) = √x en los valores 1.00, 1.25, 1.50, 1.75 y 2.00.
