Aproximación Numérica del Área por Rectángulos estilo Pixel Art

1. MISIÓN TEÓRICA

Las Sumas de Riemann dividen la región bajo una curva f(x) en el intervalo [a, b] en n subintervalos de ancho Δx = (b - a) / n. El área aproximada equivale a la suma de las áreas de los rectángulos:

Sₙ = ∑ᵢ₌₁ⁿ f(xᵢ*) · Δx, donde Δx = (b - a) / n

Puntos de Evaluación Comunes:

Izquierda (Lₙ): xᵢ* = a + (i - 1)Δx | Derecha (Rₙ): xᵢ* = a + iΔx | Punto Medio (Mₙ): xᵢ* = a + (i - 0.5)Δx

3. EJERCICIOS

1. Aproxime el área bajo f(x) = x² en usando R₄ (suma por la derecha con n = 4).

💡 Pista para iniciar: Calcula el ancho Δx = (2 - 0) / 4 = 0.5. Como usas extremos derechos, las xᵢ de evaluación son x₁ = 0.5, x₂ = 1.0, x₃ = 1.5, x₄ = 2.0. Evalúa f(x) = x² en cada valor y suma: R₄ = 0.5 · (0.25 + 1.00 + 2.25 + 4.00) = 0.5 · 7.5 = 3.7500.

2. Aproxime el área bajo f(x) = x² en usando L₄ (suma por la izquierda con n = 4).

💡 Pista para iniciar: Con Δx = 0.5, las xᵢ por la izquierda son x₀ = 0.0, x₁ = 0.5, x₂ = 1.0, x₃ = 1.5. Evalúa f(x) = x²: L₄ = 0.5 · (0.00 + 0.25 + 1.00 + 2.25) = 0.5 · 3.5 = 1.7500.

3. Calcule R₅ para f(x) = 1 / x en el intervalo.

💡 Pista para iniciar: Determina Δx = (3 - 1) / 5 = 0.4. Los puntos por la derecha son 1.4, 1.8, 2.2, 2.6, 3.0. Evalúa f(x) = 1 / x en estos 5 puntos y multiplica la suma por 0.4.

4. Aproxime ∫₀¹ eˣ dx usando R₆.

💡 Pista para iniciar: El paso es Δx = 1 / 6 ≈ 0.1667. Los puntos de evaluación por la derecha son 1/6, 2/6, 3/6, 4/6, 5/6, 6/6. Evalúa eˣ en cada punto y multiplica por Δx.

5. Calcule L₄ para f(x) = sin(x) en [0, π].

💡 Pista para iniciar: Con a = 0, b = π y n = 4, el incremento es Δx = π / 4. Los puntos por la izquierda son 0, π/4, π/2, 3π/4. Evalúa sin(x) en cada ángulo y multiplica por π/4.
