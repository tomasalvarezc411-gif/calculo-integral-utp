## 📌 Descripción del proyecto

Este repositorio contiene la **Plataforma Web Colaborativa e Interactiva de Cálculo Integral**, desarrollada para la asignatura **Matemáticas II (CB215 - Grupo 403)** del programa de Tecnología en Desarrollo de Software de la **Universidad Tecnológica de Pereira (UTP)**, durante el semestre académico 2026-II.

La plataforma combina el rigor analítico del cálculo integral con una interfaz gráfica inspirada en el universo de **Dragon Ball Z** y la estética **Arcade Retro (Pixel Art 8-Bit)**.

Su objetivo es proporcionar herramientas visuales e interactivas que permitan comprender, experimentar y practicar diferentes conceptos matemáticos mediante simulaciones en tiempo real.

Entre sus funcionalidades principales se encuentran:

- Simulación de métodos numéricos de integración.
- Visualización interactiva de integrales definidas.
- Representación gráfica de áreas entre curvas.
- Desarrollo de técnicas de integración.
- Visualización tridimensional de sólidos de revolución.
- Resolución de ejercicios mediante simuladores interactivos.
- Minijuegos educativos con preguntas y desafíos matemáticos.

## 🐉 Módulos desarrollados

La plataforma está organizada en siete módulos académicos y un recurso adicional gamificado, correspondientes a los contenidos de los dos parciales de la asignatura.

| Módulo | Archivo | Método / Tema | Estado |
|:---:|---|---|:---:|
| 01 | `module-01-riemann.html` | Sumas de Riemann (Ln, Rn, Mn) | ✅ |
| 02 | `module-02-trapecio.html` | Regla del Trapecio | ✅ |
| 03 | `module-03-punto-medio.html` | Regla del Punto Medio | ✅ |
| 04 | `module-04-simpson.html` | Regla de Simpson (1/3) | ✅ |
| 05 | `module-05-area.html` | Integral Definida y Área bajo la Curva | ✅ |
| 06 | `module-06-volumen.html` | Volumen de Sólidos de Revolución | ✅ |
| EXTRA | `module-extra-dino.html` | Dino Prehistoric Runner Quiz | ✅ |
| 07 | `module-07-parcial2-solidos.html` | Parcial II: 62 ejercicios, Sólidos 3D y Pac-Math DBZ | ✅ |

### ⚡ Módulo I: Primer parcial

Incluye los siguientes contenidos:

- **Módulo 01:** Sumas de Riemann mediante aproximaciones izquierdas, derechas y punto medio.
- **Módulo 02:** Regla del Trapecio e integración numérica.
- **Módulo 03:** Regla del Punto Medio y aproximación de integrales.
- **Módulo 04:** Regla de Simpson 1/3 y aproximación parabólica.
- **Módulo 05:** Integrales definidas y cálculo de áreas entre curvas.
- **Módulo 06:** Volúmenes de sólidos de revolución mediante los métodos de discos y arandelas.

### 🦖 Recurso adicional: Dino Prehistoric Runner

Minijuego educativo con estética retro que incorpora:

- Mecánica de juego tipo Runner.
- Preguntas aleatorias de conocimiento matemático.
- Sistema de cámara lenta.
- Elementos visuales inspirados en videojuegos clásicos.

### 🔥 Módulo II: Segundo parcial completo

El módulo 07 integra un banco de **62 ejercicios interactivos**, distribuidos en cinco bloques temáticos:

| Bloque | Ejercicios | Contenido |
|:---:|:---:|---|
| A | 18 | Potencias trigonométricas, sustitución trigonométrica, sustitución universal de Weierstrass, áreas entre curvas y secciones transversales 3D. |
| B | 12 | Funciones racionales y descomposición en fracciones parciales. |
| C | 11 | Funciones irracionales y radicales algebraicos. |
| D | 19 | Sólidos de revolución 3D: discos, arandelas, cascarones cilíndricos, proporción de Arquímedes 3:2:1 y optimización de eje. |
| E | 2 | Longitud de arco e integrales impropias. |

**🎮 Modo adicional: Pac-Math DBZ**

Incluye un videojuego inspirado en Pac-Man, con persecución mediante inteligencia artificial y personajes como Freezer, Cell, Majin Buu y Broly.

Durante la partida aparecen preguntas de cultura general matemática que permiten combinar entretenimiento y aprendizaje.

El proyecto fue desarrollado utilizando tecnologías web fundamentales:

| Tecnología | Aplicación |

## 🚀 Instalación y ejecución

### 1. Clonar el repositorio

Abre una terminal y ejecuta:

```bash
git clone https://github.com/tomasalvarezc411-gif/calculo-integral-utp.git
```

### 2. Ingresar a la carpeta del proyecto

```bash
cd calculo-integral-utp
```

### 3. Ejecutar la plataforma

Abre el archivo `index.html` directamente desde tu navegador.

**No requiere instalación de dependencias ni configuración de un servidor local para su ejecución básica.**

---

## 🌐 Despliegue en GitHub Pages

Para publicar la plataforma en internet:

1. Ingresa al repositorio en GitHub.
2. Dirígete a **Settings**.
3. Selecciona la sección **Pages**.
4. En la opción **Build and deployment**, selecciona `Deploy from a branch`.
5. Selecciona la rama `main`.
6. Selecciona la carpeta `/ (root)`.
7. Haz clic en **Save**.

Una vez finalizado el despliegue, la plataforma estará disponible en:

🔗 **[Acceder a la Plataforma Web](https://tomasalvarezc411-gif.github.io/calculo-integral-utp/)**
